# Apache Maven Shared I/O API

**Note:** This component is retired. It is no longer maintained.
Version 3.1.0 is its final release.

API for I/O support like logging, download or file scanning.

The Maven project voted to retire this component in September 2026, because it
had no remaining consumers and its download package cannot be carried to Maven 4
without breaking its published API. See the
[retirement vote](https://lists.apache.org/thread/s4oz3g4ytqpsy6odryxqhygwbty3dqt3).

If you want to continue development, fork the code under your own groupId and
artifactId. The `maven-` artifactId prefix is reserved for the Apache Maven
project, so the fork needs a different name.
